## About

Self-taught engineer based in Greece, working at the intersection of networking, software development and security. I build open source tools with a focus on defensive auditing and practical automation, taking the time to understand systems at protocol and implementation level before shipping.

My core work is Nmap NSE scripts in Lua for network service auditing, complemented by web development with Next.js and React, Discord platform automation, and game scripting. Everything I publish is designed to be safe on production infrastructure, clearly documented, and straightforward to integrate into existing workflows.

I learn by reading the documentation, building a minimal implementation, and stress testing it myself. That loop has shaped most of what is on this profile.

- **Location:** Greece
- **Role:** Network Engineer / Developer / Cyber Security
- **Focus:** Network security auditing, NSE script engineering, Discord automation, web development
- **Currently:** Hardening `Nmap-NSE-Script-Collection`
- **Portfolio:** [nexza.dev](https://nexza.dev)

## Projects

[![Nmap-NSE-Script-Collection](https://github-readme-stats.vercel.app/api/pin/?username=NexzaDev&repo=Nmap-NSE-Script-Collection&theme=chartreuse-dark&hide_border=true&bg_color=0D1117&title_color=00FF9C&text_color=c9d1d9&icon_color=1E90FF)](https://github.com/NexzaDev/Nmap-NSE-Script-Collection)

Custom Nmap NSE scripts in Lua for defensive security auditing. Each script targets a specific real world misconfiguration across services such as HTTP, DNS, SMB, SSL/TLS, FTP and databases, and reports findings in a clear, actionable format. Built to run standalone or as part of larger infrastructure scans.

## Focus Areas

- **Cybersecurity:** Defensive, non destructive auditing informed by an attacker perspective. Identify weaknesses, document them precisely, and leave systems safer than found.
- **Network Security:** Nmap and NSE coverage for common services, surfacing issues such as open resolvers, weak ciphers and unauthenticated access. Every check is written for reliable use against live environments.
- **Discord Automation:** Production grade bots for moderation, role hierarchies, XP and leveling systems, and community workflows. Built for stability under real load, not just demos.
- **Web Development:** End to end web products with Next.js, React and Node.js, with focus on performance, type safety and clean architecture. Portfolio and related projects are statically exported and deployed on Cloudflare.
- **Game Scripting:** Gameplay logic and server side mechanics on Roblox and similar platforms, used as a disciplined environment for structured and secure code.
